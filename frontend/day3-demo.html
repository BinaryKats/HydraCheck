Day 3: Hotspot Detail Components

Bottom Sheets (mobile) & Sidebars (desktop) for the Delhi Flood Monitor

Overview

Day 3 completes the detail-card experience for when users tap a colored road segment on the map. On mobile, a Framer Motion-driven bottom sheet slides up from 0% to 60% viewport height. On desktop, a fixed 25% right sidebar opens with full prediction data, recovery time visualization, and the new EDI (Effective Drainage Index) badge—the key innovation showing drainage health trends.

🚀

Responsive Design

Mobile bottom sheet, desktop sidebar—no code duplication, one prop controls layout

💧

EDI Badge

Self-updating circular badge showing drainage effectiveness (0.0–1.0 scale)

⏱️

Recovery Time

Visual bar + trend indicator showing expected waterlogging clearance time

🗺️

Map Integration

Click any colored road segment → detail sheet opens with full flood forecast
